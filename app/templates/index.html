🛒 Walmart Sales Forecasting API

End-to-end ML system for sales forecasting and anomaly detection.

Available Endpoints

POST /predict

Predict weekly sales for a store-department using XGBoost.

POST /predict → returns predicted_weekly_sales

POST /anomaly

Detect anomalies in sales time series using Isolation Forest.

POST /anomaly → returns anomaly flags and scores

GET /health

Check API status and loaded models.

GET /health → returns status

  • Isolation Forest — detected 8 anomalies including Black Friday spikes
